功能特性

为什么选择 Handy？

Handy 的诞生是为了填补一款真正开源、可扩展的语音转文字工具的空白

完全免费

辅助工具应该每个人都能使用，而不是被付费墙挡在门外

开源透明

我们一起可以走得更远。为自己扩展 Handy，为更大的事业做贡献

隐私保护

你的声音留在你自己的电脑上。获取转录而不必向云端发送音频

简单纯粹

一个工具，一个功能。转录你说的话并输入到文本框中

工作原理

四步完成语音转录

整个过程完全本地化，无需联网

1

按下快捷键

按下可配置的键盘快捷键开始录音：按住说话、松开停止，或轻按一下开启/关闭录音

2

开始说话

说话时保持快捷键激活状态，Silero VAD 会自动过滤静音

3

松开处理

Handy 使用 Whisper 或 Parakeet 模型处理你的语音

4

获取文本

转录文本直接粘贴到你正在使用的任何应用中

核心技术

Whisper 模型 Parakeet V3 Silero VAD GPU 加速 自动语言检测
下载安装

开始使用 Handy

支持 macOS、Windows 和 Linux 平台

macOS

支持 Intel 和 Apple Silicon

下载安装包 brew install --cask handy

Windows

x64 架构支持

下载安装包 winget install cjpais.Handy

Linux

x64 架构，支持 X11 和 Wayland

下载安装包 sudo apt install ./Handy_*.deb Debian/Ubuntu 请用 apt 安装 .deb，依赖会自动补齐
技术架构

现代化的技术栈

Handy 是作为 Tauri 应用程序构建的，结合了 Rust 的性能和 Web 技术的灵活性

前端

React + TypeScript

使用 Tailwind CSS 构建设置界面，提供现代化的用户体验

后端

Rust

用于系统集成、音频处理和机器学习推理

核心库

whisper-rs Whisper 语音识别
transcription-rs Parakeet CPU 优化
cpal 跨平台音频 I/O
vad-rs 语音活动检测
rdev 全局键盘快捷键
rubato 音频重采样
命令行支持

强大的 CLI 控制

通过命令行参数控制正在运行的实例和自定义启动行为，支持远程控制和自动化工作流

handy --toggle-transcription 切换录音开关
handy --start-hidden --no-tray 静默启动
handy --toggle-post-process 切换带后处理的录音
handy --debug 调试模式
第三方集成

Raycast 扩展

通过 Raycast 控制 Handy — 开始/停止录音、浏览转录历史、管理词典、切换模型和语言

手动安装模型

如果你在代理或受限网络环境中，可以手动下载和安装模型文件。支持 Whisper 的 .bin 模型和 Parakeet Unified EN 的 .gguf 模型。

查看详细步骤 →

Linux 注意事项

新安装默认使用 Shift+Insert 粘贴。Wayland 用户需要安装 wtype 或 dotool，X11 用户建议安装 xdotool。

了解更多 →

自定义 Whisper 模型

Handy 可以自动发现放置在 models 目录中的自定义 Whisper GGML 模型，支持社区微调模型。

查看方法 →

转录钩子

在 macOS 和 Linux 上，可以用脚本在粘贴前重写转录文本，例如自动加上前缀或做格式转换。

查看用法 →

粘贴了旧的剪贴板内容

在调试菜单中开启"可靠粘贴（Beta）"，或增大"粘贴延迟（之后）"，让 Handy 等接收应用读完剪贴板再恢复。

先检查 gtk-layer-shell 是否安装，再尝试 HANDY_NO_GTK_LAYER_SHELL=1 或配置 WebKit 渲染器。
