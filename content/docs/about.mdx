「关于」标签页显示应用信息和实用链接，可以从 Handy 设置窗口的侧边栏进入。

## 应用语言

修改 Handy 用户界面的语言。它与转录语言是分开的，转录语言在[模型](/docs/models)中配置。

## 版本

显示你机器上安装的 Handy 当前版本。

## 目录

- **应用数据目录** — Handy 保存配置、模型和录音的位置
- **日志目录** — Handy 写入日志文件的位置

点击即可在文件管理器中打开。各平台的默认路径见[调试 > 查找日志](/docs/debug#查找日志)。

## 支持开发

Handy 是由社区构建的免费开源软件，目前由一位开发者（[CJ](https://cjpais.com)）维护。如果 Handy 对你有帮助，欢迎支持它的开发。每一份贡献都有意义，也能让 Handy 继续对所有人免费。

你也可以通过 [GitHub Sponsors](https://github.com/sponsors/cjpais) 支持，或通过 [contact@handy.computer](mailto:contact@handy.computer) 联系赞助事宜。持续的大额赞助者可以在官网和 GitHub README 上展示 logo 和链接。

## 源代码

Handy 完全开源。你可以在 [GitHub](https://github.com/cjpais/handy) 上浏览代码、报告问题或参与贡献。

## 致谢

Handy 构建在许多优秀的开源项目之上，包括 [Whisper](https://github.com/openai/whisper) 以及其他让本地转录成为可能的语音识别模型。
