调试菜单包含隐藏在常规界面之外的高级诊断与调优设置，用于排查问题或微调 Handy 的行为。

## 打开调试菜单

用键盘快捷键打开调试菜单：

- **macOS**：`Cmd + Shift + D`
- **Windows/Linux**：`Ctrl + Shift + D`

打开后设置侧边栏会出现 **调试** 标签页，它会一直显示，直到你关闭并重新打开 Handy。

Linux 上也可以从命令行启用调试模式（见[命令行](/docs/cli)）：

```bash
handy --debug
```

## 调试设置

### 日志级别

设置日志详细程度。级别越高日志越详细，在报告 bug 或诊断问题时很有用。

- **Error** — 仅错误
- **Warn** — 错误和警告
- **Info** — 一般信息
- **Debug** — 详细调试信息（开启调试模式时的默认值）
- **Trace** — 最高详细程度

### 检查更新

开关 Handy 是否自动检查新版本，默认开启。

### 声音主题

选择录音开始/停止反馈使用的音效主题，不同主题提供不同的提示音。开始和停止一次录音即可试听。

**自定义声音**

你也可以使用自定义音频文件作为开始/停止提示音：

1. 把文件命名为 `custom_start.wav` 和 `custom_stop.wav`
2. 直接放进 Handy 的[应用数据目录](#应用数据目录)：
   - **macOS**：`~/Library/Application Support/com.pais.handy/`
   - **Windows**：`%APPDATA%/com.pais.handy/`
   - **Linux**：`~/.local/share/com.pais.handy/`
3. 打开调试菜单（`Ctrl + Shift + D` 或 `Cmd + Shift + D`），在 **声音主题** 下拉框中选择 **自定义**

*注意：如果下拉框里没有出现「自定义」选项，添加声音文件后重启 Handy。*

### 词纠正阈值

控制自定义词表纠正的激进程度，是 0.0 到 1.0 的灵敏度滑块（默认 0.18）。

- **较低的值** — 匹配更严格（只纠正非常接近的结果）
- **较高的值** — 匹配更激进（纠正更多词，但可能误纠）

它与[高级](/docs/advanced#自定义词表)设置中的自定义词表配合使用。

### 粘贴延迟

Handy 把文本复制到剪贴板与发送粘贴按键之间的延迟（毫秒），默认 60ms。

如果 Handy 粘贴了错误的文本（例如上一条剪贴板内容而不是这次转录），请增大这个值，试试 100–200ms。最大值为 200ms。

### 常开麦克风

让麦克风始终保持活动以加快录音响应。关闭时（默认）Handy 只在你按下快捷键时才激活麦克风，会带来一点延迟。

### 合盖麦克风

在笔记本上指定合盖（clamshell 模式）时使用的麦克风。如果你外接显示器并希望笔记本合盖后 Handy 自动切换到外接麦克风，这项设置很有用。

### 取消快捷键

设置一个取消当前录音的快捷键，作为按 Escape 的替代方案。

**Linux 上不可用**，因为动态注册快捷键在那里不稳定。

启用「按住说话」时此设置会被禁用，因为松开按键已经会停止录音。

## 查找日志

Handy 把日志写在磁盘上，可以从以下位置找到日志目录：

- 设置中的 **关于** 页面（查找「日志目录」）
- 调试菜单也会显示该路径

常见日志位置：

- **macOS**：`~/Library/Logs/com.pais.handy/`
- **Windows**：`%APPDATA%/com.pais.handy/logs/`
- **Linux**：`~/.local/share/com.pais.handy/logs/`

## 应用数据目录

Handy 把配置、模型和录音保存在应用数据目录：

- **macOS**：`~/Library/Application Support/com.pais.handy/`
- **Windows**：`%APPDATA%/com.pais.handy/`
- **Linux**：`~/.local/share/com.pais.handy/`

可以在设置中的 **关于** 页面打开该目录。模型位于 `models/` 子目录，录音位于 `recordings/`。
